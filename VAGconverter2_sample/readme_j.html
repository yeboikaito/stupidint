詳細

Input File テキストボックスにはエンコード対象のAIFFファイル名を指定します。
Output File　テキストボックスにはエンコード結果を書き込むVAGファイル名を指定します。 あるいは、テキストボックスの右側にある[...]ボタンを押してファイルを選択します。
[convert]ボタンを押してエンコードします。

注意事項
