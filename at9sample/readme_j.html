ATRAC9(TM) Library for PC サンプル

概要

Windows 上で ATRAC9(TM) のエンコードおよびデコードを行う Library のサンプルプログラムです。

詳細

このサンプルは、 ATRAC9(TM) ライブラリを用いて、エンコードおよびデコードを実行します。
本サンプルの出力はエンコードは ATRAC9(TM) ファイル、デコードは wav ファイル出力をします。

・エンコードコマンド書式
　at9sample -e [options] srcfilename outputfilename
　・エンコードコマンドオプション
　　-br N : ビットレート
　　　　　　(N = 36, 48, 60, 72, 84, 96, 120, 144, 168, 192, 240, 288, 300, 336, 360, 384, 420, 480, 504, 672)
　　-supframeon : スーパーフレームモード (デフォルト)
　　-supframeoff : スーパーフレームモードオフ
　　-dual : デュアルモノエンコード
　　-nbands N : エンコードバンド
　　　　　　　　　　(N = 3～18)
　　-isband N : インテンシティステレオ開始バンド
　　　　　　　　　　(N = -1, 3～18)
　　-gradmode : エンコードモード(量子化ノイズ勾配)
　　　　　　　　　　(N = 0～4)
　　-wband : 帯域優先エンコード
　　-bex : ATRAC9(TM) Band Extension
　　-slc : LFE 極低周波成分カット

・デコードコマンド書式
　at9sample -d [options] srcfilename outputfilename
　・デコードコマンドオプション
　　-int16 : 16bit Integer PCM 形式出力 (デフォルト)
　　-int24 : 24bit Integer PCM 形式出力
　　-float : IEEE float PCM 形式出力

ドキュメントは「at9sample ユーザガイド」ドキュメントを参照してください。

注意事項

- ビットレートを低く設定してエンコードを行うとエンコード出力の ATRAC9(TM) データサイズを小さくすることができますが、
　非常に低いビットレートでは符号化に必要なビットの不足によりエンコードが失敗する場合があります。
　この場合は、ビットレートを上げて再エンコードする必要があります。
- 5.1ch と 7.1ch の LFE のエンコードでは、 LFE データの入力を前提として特殊なエンコード処理を行っています。
　そのため、 LFE に高域周波数を含むデータが設定された場合には正しくエンコードされないおそれがありますので注意してください
