ATRAC9(TM) Library for PC Sample

Overview

Sample program for ATRAC9(TM) Library that performs encoding and decoding of ATRAC9(TM) files on Windows.

Explanation

This sample performs encoding and decoding using ATRAC9(TM) library.
Output of this sample is ATRAC9(TM) file by encoding and wav file by decoding.

・Form of the encoding command
　at9sample -e [options] srcfilename outputfilename
　・Option of the encoding command
　　-br N : bit rate
　　　　　　(N = 36, 48, 60, 72, 84, 96, 120, 144, 168, 192, 240, 288, 300, 336, 360, 384, 420, 480, 504, 672)
　　-supframeon : encode in superframe mode (default)
　　-supframeoff : not encode in superframe mode
　　-dual : encode as dual mono
　　-nbands N : encode band
　　　　　　　　　　(N = 3～18)
　　-isband N : intensity stereo start band
　　　　　　　　　　(N = -1, 3～18)
　　-gradmode : encode mode (quantization noise gradient)
　　　　　　　　　　(N = 0～4)
　　-wband : band priority encoding
　　-bex : ATRAC9(TM) Band Extension
　　-slc : Cut extremely low frequency component of LFE

・Form of the decoding command
　at9sample -d [options] srcfilename outputfilename
　・Option of the decoding command
　　-int16 : output 16bit Integer PCM format (default)
　　-int24 : output 24bit Integer PCM format
　　-float : output IEEE float PCM format

Please refer to the document “at9sample User's Guide”.

Note

- By encoding with low bit rates set, it will be possible to reduce the size of the ATRAC9(TM) data in encoding output,
　but for extremely low bit rates, the shortage of bits required for encoding may cause the encoding to fail.
　In this case, the bit rate must be increased and re-encoding is required.
- Special encode processing is carried out for LFE 5.1 ch and 7.1 ch encoding with the premise of LFE data input.
　Because of this, note that correct encoding may not be carried out when data with high frequencies is set to LFE.
