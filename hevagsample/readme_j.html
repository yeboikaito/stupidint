HE-VAG Library for PC サンプル

概要

Windows 上で HE-VAG のデコードを行う Library のサンプルプログラムです。

詳細

このサンプルは、 HE-VAG ライブラリを用いて、デコードを実行します。
本サンプルは wav ファイル出力をします。

・デコードコマンド書式
　hevagdec_sample [options] srcfilename outputfilename
　・デコードコマンドオプション
　　-bitPCM N : PCM 形式出力
　　　　　　　　N = 0 16bit PCM 出力 (default)
　　　　　　　　N = 1 float PCM 出力
　　-outformat N : インターリーブ出力形式
　　　　　　　　N = 0 インターリーブ出力 (default)
　　　　　　　　N = 1 非インターリーブ出力

ドキュメントは「hevagdec_sample ユーザガイド」ドキュメントを参照してください。
